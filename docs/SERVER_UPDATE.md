# 서버 갱신 5.4.0(4차시 AI 토론)

5.4.0은 5.3.0의 기록 탭·통계 기능을 그대로 포함하고 4차시 AI 토론(Upstage Solar)을 추가한다. 기존 탭·학생 행·13반·개방 설정은 유지한다. 키를 넣지 않거나 교사 화면에서 AI 토론을 켜지 않으면 4차시는 지금처럼 대본 활동으로 동작한다.

1. GitHub의 `backend/ServerBundle.gs` 전체를 기존 `Code.gs`에 교체하고 저장한다.
2. AI 토론을 쓸 경우 [AI 키 설정 안내](AI_KEY_SETUP.md) 2절대로 스크립트 속성 `L4_DEBATE_PROVIDER`·`SOLAR_API_KEY`·`SOLAR_MODEL`을 넣는다. `AI_PROVIDER`는 `none`으로 둔다.
3. `setupDB`를 한 번 실행한다. 2차시·4차시 기록 탭, AI 토론 탭 2개(`l4_debate_turns`·`l4_debates`), config의 4차시 방식 3줄이 없으면 추가한다. 기존 제출은 기록 탭에 한 번만 정리한다.
4. 키를 넣었다면 `testSolarConnection`과 `testDebateSample`을 실행해 로그를 확인한다.
5. **배포 → 배포 관리 → 기존 배포 수정 → 새 버전 → 배포**로 갱신한다. 같은 `/exec` 주소를 유지한다.
6. 공개 `ping`이 `5.4.0`인지 확인하고, 교사 화면에서 4차시 활동 방식을 정한다.

기록문은 외부 AI 호출 없이 실제 제출 원문으로 만든다. 관찰 기록문은 협력 과정·태도·의학적 진위·성취도를 추정하지 않는다. AI 토론의 활동 기록문에는 모둠의 질문·답변·반박과 성찰만 이어 쓴다. 단계별 안내는 대화에서 한 단계씩 진행한다. 실제 키 입력·배포·Upstage 왕복이 끝나기 전에는 AI 토론 연결 완료로 기록하지 않는다.
