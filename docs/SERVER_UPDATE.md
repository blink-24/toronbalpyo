# 2·4차시 서버 갱신

서버 버전 5.1.0은 이전 자체 검토 보완과 4차시 모둠 대본·차시 개방 설정을 한 번에 포함한다. GitHub Pages 게시만으로 Apps Script가 갱신되지는 않는다. 최초 서버를 사용 중이면 2차시는 계속 사용할 수 있고, 4차시는 준비 중으로 표시한다.

## 소유자 작업 순서

대화에서는 한 단계씩 안내한다. 교사 암호·API 키를 대화나 GitHub에 보내지 않는다. 이번 4차시는 대본 모드이므로 새 AI 키가 필요 없다.

1. Apps Script 편집기에서 기존 `Code.gs`를 열고 [서버 코드 전체](https://github.com/blink-24/toronbalpyo/blob/main/backend/ServerBundle.gs)의 내용으로 **전체 교체 후 저장**한다. 기존 코드 뒤에 추가하지 않는다. `appsscript.json`과 기존 스크립트 속성의 PASSCODE·SPREADSHEET_ID는 유지한다.
2. 함수 선택에서 `setupDB`를 골라 한 번 실행한다. 기존 데이터는 남기고 `l4_sessions` 오른쪽에 11개 헤더만 추가한다. 28열에서 39열로 확장하며 기존 개방 설정을 덮어쓰지 않는다.
3. **배포 → 배포 관리 → 기존 웹앱의 연필 아이콘 → 버전: 새 버전 → 배포**로 갱신한다. 기존 배포를 갱신하여 같은 `/exec` 주소를 유지한다.
4. 공개 `ping`의 version=5.1.0, config의 implementedLessons=[2,4], l4AiEnabled=false를 확인한다. 실제 저장·교사 암호 로그인·교사의 열기/닫기는 별도로 확인한다.
5. 교사용 화면에 로그인하고 4차시 열기를 누른다. 기본값은 2차시만 열림이며 두 차시를 모두 닫을 수도 있다. 학생 화면에는 최대 15초 안에 반영되며 서버는 학생 요청 때마다 닫힘을 검사한다.

소유자 작업 전에는 새 서버의 실제 Google 저장·개방 제어를 적용 완료로 표시하지 않는다. 기존 2차시 자료·개인 초안과 원본 수업 자료는 보존한다.

## 포함한 서버 보완

- 모둠원 4~5명·같은 반·대표 포함 검증, 같은 모둠명/명단의 대표 변경 복원, 모둠 기준 최신 결과
- 4차시 입론①/⑤·3~5문항·가상 자료·피드백·성찰의 서버 재계산, 실제 AI 호출 없음
- 교사 인증 후 acceptLessons 변경, 모두 닫힌 빈값 보존, 잠금 안 개방 재확인
- 제출 중복·늦은 질문·부분 저장·캐시 장애 복구, 셀 길이·수식·상태 크기 검사
- 헤더 추가 전 열 공간 확장, 기존 행·메모·설정·머리글 보존
