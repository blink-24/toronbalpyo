# 기록 탭·통계 서버 갱신5.3.0

GitHub의backend/ServerBundle.gs전체를기존Code.gs에교체하고저장한다. 다음setupDB를한번실행하면동일스프레드시트에2차시·4차시탭을자동생성하고기존제출을추가정리한다. 원래탭·학생행·13반/개방설정은유지한다. 두탭에는식별정보·입장·활동기록문·교사용관찰기록문이들어가며공개공유로보내지않는다.

이후배포관리에서기존웹앱의새버전으로갱신한다. 같은exec주소를유지하면화면주소변경이필요없다. 새배포를만들었다면새주소를알려야한다. 실제ping5.3.0확인후반별전체통계를확인한다. 복사·저장→setupDB→배포는대화에서한단계씩안내한다.

정리문은외부AI호출없이실제제출원문·답변수·도움자료선택기록·성찰로구성한다. 관찰문은협력과정·태도·의학적진위·성취도를추정하지않는다. 제출ID로중복을막고정리탭쓰기실패후재전송에서복구한다. 교사는필요시기록문을검토한다. 원래제출을수정해도기존정리문을자동덮어쓰지않는다.
