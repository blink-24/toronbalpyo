## 감지와 선택

NFKC 정규화 뒤 공백·문장 부호·기호를 제외한 문자열로 표현을 찾는다. 수치 단서는 %와 소수점·숫자 경계를 보존해 70%와70회,30.3과303을 혼동하지 않는다. 단순히 반복한 횟수는 점수에 더하지 않는다. 단서별 고유 표현 최대3개와 가장 긴 표현의 길이를 제한해 점수화한다. 보류 근거와 원출처 검토 단서는 우선한다.

관련 대본이 일반 대본보다 먼저 고려된다. 다만 신뢰성·타당성·공정성을 한 번씩 포함하고 같은 대상이나 매우 비슷한 질문을 반복하지 않는다. 같은 단서의 두 변형은 모둠 세션 시드로 하나만 선택한다. 남은 자리에는 서로 다른 관련 단서를 채운다. 어떤 단서도 없으면 기존 일반 질문으로 진행한다. 따라서 감지된 모든 단서가3~5개 문항에 모두 등장하는 것은 아니다.

감지는 의미 이해나 사실 판정이 아니다. 부정·조건·상대방 주장 인용도 단어가 있으면 감지될 수 있으므로 실제 입력 문장을 그대로 확인하고 조건을 묻는다. 입력하지 않은 구체적 주장을 만들어 인용하지 않는다. ①·⑤에서 단서가 있는 문장을 찾고 긴 문장도 단서 주변을 인용한다.

기존1.0.0 세션의 계획·질문·도움 자료는 그대로 복원한다. 서버가 l4ScriptVersion1.1.0을 알리기 전에는 화면도 기존 대본으로 새 활동을 시작한다. 이후 새 활동만1.1.0으로 시작하며 진행 중 세션을 재계획하지 않는다.
