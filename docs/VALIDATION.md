# 검증 기록

2026년 10월 26일, 수업안 v6·웹앱 스펙 v5 기준 로컬 코드 검사 결과다.

- `npm test`: 34개 통과. 대본의 32조합, 기준·겨냥 대상·심각도, 피드백 원문 예시, 첫 답 잠금, 2답 종료, 개인정보·허용값·길이·수식 입력, 중복 제출, 서버 재계산, 교사 인증, 익명 집계, AI 실패·늦은 응답 복구, 초안·전송 큐·전체 대담 프로토콜을 포함한다.
- `npm run check`: 모듈 문법·상대 import·공개 키 형태·UTF-8·모바일 viewport 검사 통과. 공개 JS 전체를 합쳐 gzip 35,339바이트로 200KB 기준 이내다.
- `node backend/sync.mjs --check`: 브라우저·Node 엔진과 Apps Script 번들·콘텐츠 일치.
- `npm run build`: 공개 허용 목록만 `dist/`로 복사. 서버 코드·프롬프트·문서·시험·사용자 원본은 배포물에 포함하지 않는다.
- DB 양식: 실제 서버의 9탭·155개 헤더와 일치. 설정 8행 외 데이터가 없고 학생·샘플·비밀값을 넣지 않았다.

시험은 Node와 Google 서비스의 모형 저장소에서 실행했다. 실제 Google Sheets 쓰기·교사 암호 조회·브라우저 CORS·GitHub Actions·Pages·학교 태블릿·AI 공급자 호출의 검증 결과가 아니다. 사용 가능한 브라우저 검사 경로가 없어 실제 화면 실행·스크린샷 검사는 하지 않았다. 모바일 배치와 접근성은 HTML·CSS·상태 및 네트워크 코드 구조를 확인한 범위다.

외부 계정 연결과 배포 후에는 가상 입력으로 실제 왕복을 확인하고 이 기록에 그 결과를 추가한다. 현재 상태는 [DEPLOYMENT_STATUS.md](DEPLOYMENT_STATUS.md)에 있다.

## 2026년 10월 27일 추가 확인

- 동일 구현의 로컬 34개 자동시험·프로젝트 검사·번들 일치·빌드를 재실행해 통과했다.
- GitHub PR #1의 Checks가 실제 성공했고, 검증된 구현을 main에 병합했다. 원격 Git tree와 로컬 39개 텍스트 소스의 tree SHA가 일치한다.
- main의 Pages 실행도 테스트·검사·빌드와 공개 파일 경계 검사를 통과했다. 저장소 Pages가 활성화되지 않아 Configure GitHub Pages에서 Not Found로 실패했으며 실제 사이트는 게시되지 않았다.
- 요청한 개인 계정 소유·비공개 Google Sheets를 실제 생성했다. 메타데이터와 셀 읽기로 9탭·155헤더·초기 설정 8행·한국 시간대를 확인했다. 학생 기록은 넣지 않았다.
- Google에서 내보낸 XLSX를 Artifact Tool로 가져와 9탭의 채워진 영역을 확인했다. 영문 헤더는 잘림·겹침이 없었다. config 한글 값은 보존됐지만 로컬 import/render에서 미표시되며 변환 전 원본 XLSX에서도 같은 현상이 재현됐다. 이 경로의 한글 시각 검증은 호환 한계가 있고 Google 실제 화면 오류로 단정하지 않는다.
- Apps Script 최초 권한 승인·배포와 실제 브라우저/시트 왕복은 아직 대기 중이다. Node 모의시험이나 시트 생성 성공을 실서비스 연결 검증으로 바꾸어 기록하지 않는다.
