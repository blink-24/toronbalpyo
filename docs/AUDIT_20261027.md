# 2차시 웹앱 자체 검토

확인일: 2026년 10월 27일(한국 시간). 사용자 요청에 따라 실제 학생 자료 대신 지정한 시험 번호 21199로 검토했다. 수업안·최종 PPT·학습지 원본은 수정하지 않았다.

## 수정과 적용

| 확인한 문제 | 수정 | 적용 상태 |
|---|---|---|
| 화면 갱신이 입장 학번을 지움 | 로그인 폼 값·포커스·커서를 DOM에서만 보존 | 프런트 게시 완료 |
| 이전 화면·같은 선택 재클릭 시 수정 입론 유실 | 실제 선택 변경 때만 초안 무효화. 비워서 수정 중인 상태도 보존 | 프런트 게시 완료 |

교사 암호는 폼 값 복원 중에도 HTML 속성이나 localStorage에 저장하지 않는다. 실제 교사 암호를 수집하거나 시험에 사용하지 않았다.

## 검증 근거

- Node 회귀·기존 시험 53개 통과. 고의 장애·경합·이전 단계 이동·빈 초안·재전송·주소 고정·로그인 포커스를 포함한다.
- [브라우저 검사](https://github.com/blink-24/toronbalpyo/actions/runs/40486318647): 수정 후보 화면을 실제 Google 서버와 연결해 데스크톱 3문항, 모바일 크기 오프라인 2문항 조기 종료·재연결 저장을 통과했다. 학습 19장·자료 인용·초안 복원·입력 보존·익명 공유·무암호 교사 접근 거부도 확인했다.
- 실제 시트에서 세션마다 한 행과 문항 수·전송 모드를 확인했다. 중복 전송은 duplicate ACK였고 추가 제출 행이 없었다.
- [수정분 게시](https://github.com/blink-24/toronbalpyo/actions/runs/40486746828): Pages 게시와 HTML·API 설정·메인 모듈·스타일 HTTP 확인 성공.
- 스크린샷은 가상 시험만 포함한다. 검사 증거는 CI에 3일 보관하며, 정상 수업 데이터와 함께 저장하지 않는다.

## 시험 기록 정리

자동 검사에서 만든 세션 3개의 sessionId/submissionId를 먼저 기록했다. 실제 시트와 대조 후 일치하는 제출 3행·대담 로그 18행·진행 28행, 합계 49행만 삭제했다. 재조회에서 해당 세션 참조가 없음을 확인했다. 사용자 입장 시험의 기존 진행 기록이나 다른 학생 자료를 일괄 삭제하지 않았다.

브라우저 전체 활동 검사는 실제 시트에 시험 행을 쓰므로 이후에는 **Classroom browser audit → Run workflow**로 명시적으로 실행한다. 일반 PR·배포에서는 이 쓰기 검사를 자동 반복하지 않는다. 일반 Node 검사와 공개 API 읽기 검사는 계속 자동 수행한다.

## 남은 범위

현재 배포 Apps Script는 최초 버전이다. 새 서버 보완은 [SERVER_UPDATE.md](SERVER_UPDATE.md)의 소유자 코드 교체·기존 배포 새 버전 갱신이 필요하다. 소유자 배포가 끝나기 전에는 서버 보완을 실서비스 적용 완료로 표현하지 않는다.

학교 실제 태블릿·망, 교사 실제 암호 로그인, 선택적 AI 공급자 호출은 이번 검증에 포함하지 않았다. 자동 브라우저의 모바일 크기 검사를 실제 학교 기기 시험이라고 부르지 않는다.
