# 콘텐츠 근거와 정규화

## 현재 기준

## 2차시 구현 콘텐츠 대응

`data/content.json`이 콘텐츠 정본이다. `src/core/content.js`는 브라우저와 Node가 빌드 도구 없이 함께 읽을 수 있는 동일 데이터 사본과 조회 함수를 내보낸다. 두 객체의 동등성을 검사한다. 수정할 때 두 파일을 함께 갱신한다.

학습 요약은 `[최종] 2차시 PPT_토론.pptx`(SHA-256 `9eec7304200e7475a8e5d6a09c899dd02c732a46c1a3a4f4efaea0ca90abea03`)의 19장을 기준으로 한다. 앱용 요약의 제목·설명은 자체 문장이며 PPT 원본의 재출력본이 아니다. 교과서 202쪽 입론의 긴 본문·실험 수치·실제 통계는 앱이나 AI 프롬프트로 옮기지 않는다.

## 원문을 실행용으로 나눈 항목

- 카드·질문의 ID는 원문 그대로다. 입장은 한글 `찬성`·`반대`·`공통`을 정본 값으로 유지하며, 화면 선택 편의를 위한 `stanceId`만 추가했다.
- Q-REL-GEN의 원문에는 시기가 없는 경우의 작성 지시가 같은 칸에 들어 있다. 원문은 `sourceConfirm`, 실행 문구는 `confirm`·`confirmWithoutYear`로 나누었다. 작성 지시가 학생 질문으로 출력되지 않게 하기 위한 정규화다.
- 도움 카드 H5~H12에 없는 연도·조사기관은 만들지 않았다. `source`·`citation`은 카드에 적힌 가상 자료명으로 구성하고, 기재되지 않은 연도는 `null`이다.
- `targetKey`는 중복 확인을 검사하기 위한 메타데이터다. RN2의 타당성 질문은 벌금 반대 결론과의 연결(`stance.policyLink`), 공정성 질문은 책임 편중(`reason.blame`)으로 구분했다. 두 질문의 실제 문구는 바꾸지 않았다. 이는 v5의 “이유의 다른 면을 묻는다”는 설명과 확인 대상 중복 방지 조건을 함께 반영한 구분이다.

## 학생 화면의 노출 경계

- 모든 근거·도움 카드는 **수업용 가상 자료** 띠와 함께 제시한다. ‘한빛시’는 가상 지명이다.
- `reliability`, `weakness`, 질문의 `criterion`·`targetKey`는 내부 계획·피드백용 메타데이터다. 카드 선택·대담 중 정답 표식처럼 표시하지 않는다.
- 질문이 겨냥한 기준은 대담이 끝난 피드백에서 공개한다. 대본 모드를 위해 필요한 메타데이터가 정적 소스에 있어도 UI 공개 시점은 별도로 지킨다.
- AI 시스템 프롬프트·API 키·교사 암호는 이 콘텐츠나 클라이언트 모듈에 없다.
- 교사 화면의 공개 투사에서는 학번을 가린다. 공개 공유 API에는 학생 원문·개인별 기록을 내보내지 않는다.

## 차시 구분

2차시는 개인 18분 체험이며 모둠 번호·녹음 제출을 요구하지 않는다. 국격 과제와 옛 M1~M6 퀴즈는 v5에서 폐기됐다.

4차시는 같은 모둠의 입론을 대상으로 대본 토론자가 3~5개 질문을 하고 모둠이 답한다. 사용자 확장 요청에 따라 의료 정책 논제의 독자 질문 22개·가상 도움 자료 33개를 추가했으며 2차시 카드의 이름만 바꾸어 재사용하지 않았다. 실제 AI는 호출하지 않는다. [4차시 확장 계약](LESSON4_IMPLEMENTATION_CONTRACT.md)을 따른다.

## 검증 범위

v5 표에서 파싱한 이유 7개·근거 카드 8개·대본 질문 24개·도움 카드 12개의 문구가 정규화 JSON과 정확히 일치함을 확인했다. 입장별 근거 4장·이유 선택 4종, 모든 기준·입장의 도움 자료 후보 2장 이상, 단계 시간 합계 1,080초, 학습 요약 19개를 확인했다. Node에서 CONTENT 모듈 객체와 JSON의 완전 일치도 통과했다.

엔진 분기와 피드백의 실제 시험 결과, 프런트엔드·Google 연동·배포 결과는 각 담당의 검증 기록과 구분한다.

## 4차시 자체 작성 대본·가상 자료

`data/lesson4.json`이 4차시 정본이며 `src/core/lesson4-content.js`의 named/default `LESSON4_CONTENT`와 동일하다. 콘텐츠 버전은 1.0.0, 2차시 콘텐츠는 5.0.0, 서버 확장은 5.1.0으로 구분한다. 수업안 내부 v6와 개선 토론문 `06_discussion_passage.docx` 전체를 읽고 작성했다. DOCX 해시는 `6504533a8ff4d857de94885c1d2147b62a6f8d7ea17ac55bf7ff478a784607ce`이며 수업 자료 자체를 이 저장소에 복제하지 않는다.

| 검토 단서 | 대본에서 다루는 범위 |
|---|---|
| ② 길 안내 사례 | 다른 기술의 가능성과 의료 상담 성능의 직접 증거를 구분 |
| ③·④ 법과 책임 | 법 정의와 구체적 서비스 적용·책임 분담·오류 대응을 구분 |
| ⑥ 이용 격차 | 비대면 진료 이용과 AI 이용 능력의 차이, 이용 지원·대체 창구 검토 |
| ⑦ 불명확한 설문 | 의사 열 명 중 일곱 명은 검토용 출처 오류. 원출처 확인 전 검증된 사실로 쓰지 않음 |
| ⑧ 기업 사건 | 경영·서비스 지속과 기술의 임상적 실패를 구분 |
| ⑨~⑫ 도입 조건 | 진료 연결·정보 보호·운영 조건·대안 비교의 정책 논증 검토 |
| 근거 카드 5·6 | 원자료 확인 전 사용 보류 유지. 수치·출처를 새로 만들어 채우지 않음 |

22개 질문은 찬성·반대 각 11개 주제로 구성한다. 학생 입론 ①·⑤의 문장과 단어 단서를 사용해 겨냥 대상을 정하고, 세 기준을 포함한 서로 다른 대상 3~5개를 선택한다. 유사한 검증 질문을 함께 넣지 않고 시드가 같으면 순서·도움 자료를 복원한다. 이는 규칙에 따른 단서 매칭이며 자유 글의 의미를 AI가 완전히 이해하거나 사실을 검증한 결과가 아니다. 학생 입론을 대필하는 함수는 제공하지 않는다.

가온군·가온보건소 등의 33개 도움 카드는 모두 자체 작성한 **수업용 가상 자료**다. 운영 초안·비교표·검토 틀로 구성하고 실제 기관의 조사 결과나 새 의료 통계를 만들지 않았다. 각 질문에서 관련 자료 2~3개를 시드에 따라 제시하며 가상 띠·출처·자료 번호를 함께 표시한다. 개인 증상·진단·치료에 대한 건강 조언은 제공하지 않는다.

피드백은 현재 자료 인용·출처 표현, 이유와 정책 주장의 연결 표현, 인정·회피 표현을 점검하는 휴리스틱이다. 실제 진위·의학적 타당성·법률 적용을 판정하거나 수업 점수로 사용하지 않는다. ⑦의 모호한 설문과 보류 근거를 확인된 사실처럼 쓰는 표현은 별도 경고한다. 질문의 기준·숨은 검토 방향은 대담 뒤 피드백에서 공개한다.

모둠명·모든 학번은 콘텐츠나 순수 엔진 입론 필드에 섞지 않고 서버 별도 필드에 둔다. 공개 집계에는 이들 식별정보와 학생 원문을 포함하지 않는다. 실제 AI 호출·학교 정책 승인·실서버 적용의 완료를 콘텐츠 제작으로 대체하지 않는다. 전용 엔진 시험 26개에서 정본 동등·양 입장 3/4/5질문·시드 복원·다양성·중복·인용·첫 답 잠금·길이·피드백 회귀를 확인했다. 통합·브라우저·외부 연결의 최종 결과는 각 검증 기록을 따른다.
