## 4차시 운영 의견 반영: 토론 흐름·응수·제한 시간(2026-11-02)

사용자가 4차시를 운영했을 때 교사 화면의 4차시 방식이 '대본'이어서 질문·답변만 보였다(AI 입론·모둠 신문·반박이 없는 화면). 12단계 흐름은 교사 화면에서 '4차시 활동 방식 → AI 토론'을 선택해야 나온다. 사용자 요청에 따라 AI 토론을 다음처럼 고쳤다. AI 입론(최대 500자)·반박(최대 450자)은 실제 자료를 근거로 끝맺는 완결 발언으로 쓰게 했다. 반대 신문에서는 직전 모둠 답에 두 문장 이하로 짧게 응수한 뒤 질문하고(최대 260자), 모둠 질문에는 160자 이내로 짧게 답한다. 모둠 차례에는 제한 시간(질문 1:30·답변 1:30·반박 2:30)을 두고, 시작 화면에 먼저 알린다. 시간이 끝나면 쓴 내용, 없으면 안내 문장을 보낸다. 로컬 196시험과 Chromium 가상 모둠 전체 진행(모바일·데스크톱, 교사 방식 전환)을 통과했다. 실제 Solar 응답의 응수 품질은 교사 미리보기·리허설로 확인한다.

## 교사 대시보드 지연·4차시 방식 미표시(2026-11-02)

읽기 전용 실제 API 검사([실행 41376346960](https://github.com/blink-24/toronbalpyo/actions/runs/41376346960))에서 공개 서버가 5.3.0으로 응답했다. Apps Script 코드는 저장했지만 웹앱 배포에 새 버전을 적용하지 않은 상태로 보인다. 편집기 메뉴는 저장한 코드로 실행되므로 동작했다. 교사 화면은 서버가 이전 버전이면 4차시 방식 자리에 새 버전 배포 안내를 보이도록 바꿨다.

대시보드 지연의 원인: 2차시 요약이 진행 행마다 진행 탭 전체를 다시 읽었고, 4차시 요약은 토론마다 차례 탭을 다시 읽었다. 조회 요청 안에서는 같은 탭을 한 번만 읽게 하고(200행 시험에서 진행 탭 읽기 1회), 화면은 요약·목록을 동시에 요청한다(마감 40초). 실제 서버에 새 버전을 배포한 뒤에 적용된다.
